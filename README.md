## 为什么做 ToolSide

以前处理一个小需求，流程是这样的：**新开标签页 → 搜索工具网站 → 等页面加载 → 上传文件 → 处理 → 下载**。压个图要开三个网站，JSON 格式化要收藏一堆网址，收藏夹越堆越厚，用的时候还是找不到。

ToolSide 把这些高频小工具全部收进浏览器侧边栏：**随开随用，用完即走**。工具不该藏在收藏夹里，它应该出现在问题发生的地方。

> The best product is the one already open when the user realizes they need it.

## ✨ 四个每天都会用到的能力

### 📋 跨标签页剪贴板

在任意标签页复制的文字、链接与图片自动进入剪贴板历史，随时回到侧边栏取用。

- 多标签页共享，切换页面内容不丢失
- 侧边栏一键复制，或导出为 txt / 图片下载
- 支持置顶与搜索，找回上周复制的内容

### 📸 截图与录屏

- 自定义区域 / 整页长截图 / 可视区域截图三种模式
- 录制标签页或屏幕视频，随录随存
- 截完即在侧边栏标注、复制或下载

### 🌐 翻译

- 划词翻译，浮层即时显示
- 整页翻译，支持原文对照
- 翻译结果可直接存入剪贴板

### 🖱️ 右键直达

在网页任意位置右键，常用工具直接出现在菜单里，选中即用：

| 右键对象 | 可用工具 |
| --- | --- |
| 图片 | 压缩、格式转换、提取颜色、OCR |
| 文字 | 划词翻译、翻译整页、AI 总结 |
| 页面 | 加入剪贴板、截图 / 录屏 |

## 🚀 核心特性

- **搜索即用** — 输入关键词直达工具，中英文与别名都能命中，不用记菜单在哪
- **常驻侧边栏** — 与网页并排显示，收起后只占 36px 极窄入口，不打扰阅读
- **快捷键唤起** — `⌘ Shift T` 打开侧边栏，`⌘K` 聚焦搜索，全流程键盘可达
- **右键直达** — 右键图片或选中文本，直接调用压缩、OCR、翻译等工具
- **🔒 本地处理** — 图片、PDF、文本默认在本地完成处理，不上传服务器
- **⭐ 我的工具** — 收藏常用工具与网站，自定义打开方式：侧边栏或新标签页

## 📖 三步，解决问题

```
1. 遇到问题    网页上的图片太大、PDF 需要合并、一段外文看不懂
2. 点开 ToolSide    点击右侧极窄入口或按快捷键，侧边栏即时展开
3. 搜索并使用    输入关键词，选中工具，在侧边栏里直接完成
```

无需切换标签页，无需离开当前页面。
